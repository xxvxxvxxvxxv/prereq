PREREQ 2.2.1 - independent prerequisite lookups

This package changes PREREQ only. No account was accessed and no deployment
was made while producing it.

For an existing 2.2 installation, the production code changes are only:
  prereq/__init__.py
  prereq/app.py
  prereq/banner.py
  prereq/service.py
  web/app.js

No change to Render environment settings, hosting, domain or credentials is
required by this patch. Python 3.11+ remains supported. The /health response
reports 2.2.1 after this version is actually deployed by its operator.

The full-catalog-first dependency is removed. All majors use the same
course-specific source reader; validated term/course facts are shared.

Local run: python3 start.py
Tests: python3 -m unittest discover -s tests -v

The EE example was bundled data, not proof of successful live retrieval.
This patch does not add fabricated prerequisites or relabel old rules with a
new term. Exact-source server behavior still needs live verification because
this runtime cannot resolve the university host. Read docs/TESTING-2.2.1.md.

This is a complete local source package, not an already-published website.
No GitHub automation or publishing helper is included.
